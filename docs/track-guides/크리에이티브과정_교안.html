MODULE 02 · DAY 5–8
M02 · 이미지 생성

나노바나나 완전 정복
— AI 이미지 프롬프트 마스터

생각한 것을 그대로 이미지로 만들어내는 것은 기술이 아닙니다. 좋은 프롬프트를 쓰는 것입니다. 나노바나나로 원하는 이미지를 정확하게 생성하는 프롬프트 공식을 마스터합니다.

📅 Day 5–8
🖼 이미지 프롬프트
🎨 스타일 컨트롤
⏱ 약 100분
이 모듈을 마치면
  • SCSE 이미지 프롬프트 공식(Subject·Context·Style·Extra)을 적용할 수 있다
  • 원하는 스타일(사진/일러스트/3D/포스터)로 정확하게 이미지를 생성할 수 있다
  • 생성된 이미지를 네거티브 프롬프트와 파라미터로 세밀하게 조정할 수 있다
이미지 프롬프트 공식
1
이론
SCSE 이미지 프롬프트 공식 — 원하는 이미지를 정확하게
20분

이미지 생성 AI에서 결과물의 90%는 프롬프트에 달려있습니다. "예쁜 카페 사진"처럼 막연하게 쓰면 막연한 결과가 나옵니다. SCSE 공식으로 구조화하면 원하는 것이 나옵니다.

요소설명예시
S — Subject주제·주인공 (무엇을 그릴 건지)젊은 여성 바리스타, 라떼 아트를 만들고 있는
C — Context배경·환경·상황 (어디서, 어떤 분위기)따뜻한 아침 햇살이 드는 원목 인테리어 카페에서
S — Style스타일·렌더링·분위기필름 사진 스타일, 따뜻한 색감, 보케 효과
E — Extra추가 파라미터·품질·비율4K, 상업 사진, 16:9 와이드
Claude로 이미지 프롬프트 생성하기
이미지 프롬프트 자체를 Claude에게 만들게 하면 훨씬 좋은 결과가 나옵니다. "이런 이미지를 만들고 싶어 → Claude가 상세 프롬프트 작성 → 나노바나나에 입력"이 가장 효율적인 워크플로우입니다.
이미지 프롬프트 생성 + 스타일 변형
이미지 AI
# Claude로 나노바나나 프롬프트 생성 나노바나나(AI 이미지 생성)에 쓸 프롬프트를 써줘. 내가 만들고 싶은 이미지: [원하는 이미지 설명 — 한국어로 자유롭게] 사용 목적: [SNS 포스팅 / 광고 / 제품 이미지 / 브랜딩 등] 요구사항: - 스타일: [사진 실사 / 일러스트 / 3D / 미니멀 / 레트로 등] - 색감: [따뜻한 / 차가운 / 파스텔 / 모노크롬 등] - 비율: [정방형(1:1) / 세로(4:5) / 가로(16:9)] SCSE 공식으로 구조화된 프롬프트를 3가지 버전으로 만들어줘. 각각 조금씩 다른 해석으로. # 스타일 변형 프롬프트 세트 같은 주제를 5가지 스타일로 표현하는 프롬프트 세트를 만들어줘. 주제: [예: "서울의 카페 풍경"] 스타일별 프롬프트: 1. 현대 상업 사진 스타일 2. 수채화 일러스트 스타일 3. 레트로 필름 사진 스타일 4. 미니멀리즘 그래픽 스타일 5. 팝아트 스타일 # 네거티브 프롬프트 (원하지 않는 것 제거) 다음 이미지 생성에서 피해야 할 요소를 네거티브 프롬프트로 정리해줘. 피하고 싶은 것: [흐릿한 이미지, 인공적인 느낌, 과도한 필터, 왜곡된 얼굴 등]

브랜드 비주얼 시스템
— 일관된 이미지 제작

좋은 브랜드는 이미지 하나하나가 아닌 전체적인 일관성에서 나옵니다. AI 이미지를 브랜드 시스템으로 연결하는 방법을 배웁니다.

📅 Day 9–12
🎨 브랜드 일관성
📐 스타일 가이드
⏱ 약 90분
이 모듈을 마치면
  • 브랜드 이미지 스타일 가이드를 Claude로 정의할 수 있다
  • 동일한 스타일을 반복 생성하는 "시드 프롬프트" 시스템을 만들 수 있다
  • 로고·제품·라이프스타일 이미지를 통일된 톤으로 제작할 수 있다
브랜드 이미지 스타일 가이드 + 시드 프롬프트
브랜드 시스템
# 브랜드 이미지 스타일 가이드 다음 브랜드의 AI 이미지 스타일 가이드를 만들어줘. [브랜드 정보] 브랜드명: [이름] 업종/제품: [설명] 타겟 고객: [누구] 브랜드 컨셉: [따뜻함 / 모던 / 프리미엄 / 친근함 등] 스타일 가이드 포함 내용: 1. 색감 팔레트 (3~5가지 주요 색상 + 느낌) 2. 이미지 스타일 (어떤 렌더링 방식) 3. 조명 방향과 분위기 4. 구도 원칙 (클로즈업/와이드/여백 활용) 5. 피해야 할 요소 목록 (네거티브 지침) # 재사용 가능한 시드 프롬프트 위 스타일 가이드를 기반으로 모든 이미지에 고정으로 붙일 "시드 프롬프트"를 만들어줘. 형식: "[주제 설명], [고정 스타일 요소들]" 이 시드 프롬프트에 앞에 주제만 바꾸면 항상 같은 브랜드 톤이 나오도록. 예시 주제별 테스트: - 제품 이미지 버전 - 라이프스타일 이미지 버전 - 팀/사람 이미지 버전 - 배경 텍스처 버전
