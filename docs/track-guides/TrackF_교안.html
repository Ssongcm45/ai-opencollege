M01 · 자기 분석

나를 분석하라
— 강점·가치관·커리어 방향 설정

취업 준비에서 가장 먼저 해야 할 것은 회사 리스트가 아닙니다. 나 자신을 객관적으로 아는 것입니다. AI는 내가 보지 못한 강점과 패턴을 찾아내는 데 탁월한 파트너입니다.

📅 Day 1–4
🧭 자기 분석
🎯 방향 설정
⏱ 약 90분
이 모듈을 마치면
  • STAR 방법론으로 과거 경험을 취업 자산으로 전환할 수 있다
  • Claude와 함께 나만의 강점 키워드 10개를 도출할 수 있다
  • 목표 직군 2~3개를 구체적으로 설정하고 그 이유를 설명할 수 있다
이론 강의
1
이론
AI 자기 분석 — "나를 모르면 자소서를 못 쓴다"
18분

자기소개서의 80%가 평범한 이유는 자신을 모른 채 쓰기 때문입니다. "열정적이고 책임감 있으며 소통을 잘합니다"라는 문장은 1000명이 똑같이 씁니다. AI를 활용해 나만의 구체적인 경험과 강점을 발굴하는 것이 먼저입니다.

STAR 프레임워크
Situation (상황) → Task (과제) → Action (행동) → Result (결과)
이 구조로 경험을 정리하면 어떤 질문에도 구체적으로 답할 수 있습니다. Claude가 경험 하나를 STAR로 분해해줍니다.

취업 분석
# STEP 1: 경험 STAR 분해 내 경험을 STAR 방법론으로 분석해줘. [경험 설명] [대학 수업 팀프로젝트, 동아리 활동, 아르바이트, 봉사활동 등 구체적으로] 각 경험에서: - Situation: 어떤 상황이었는지 - Task: 내 역할과 과제 - Action: 내가 한 구체적 행동 (동사 중심) - Result: 결과와 배운 것 (수치 포함 가능하면) # STEP 2: 강점 키워드 도출 위 경험들에서 반복되는 나의 강점 패턴을 찾아줘. 포함할 것: - 강점 키워드 10개 (동사 + 명사 형태로) - 각 강점의 근거 경험 (위에서 분석한 것) - 이 강점이 빛나는 직무 유형 - 면접에서 자주 나오는 강점 질문 5개 + 내 경험 기반 답변 # STEP 3: 커리어 방향 설정 나의 강점, 흥미, 가치관을 바탕으로 지원하기 좋은 직무 방향 TOP 3를 추천해줘. 내 정보: - 전공: [전공] - 흥미 분야: [관심 분야들] - 강점: [위에서 나온 강점] - 원하는 워크스타일: [사무직/현장/재택/출장 등] 각 직무 방향에 대해: - 직무명 + 하는 일 설명 - 내 강점이 어떻게 적합한지 - 주요 취업 회사 예시 5개 - 필요한 추가 역량

§8 강사 노트
가장 흔한 실수: "저는 특별한 경험이 없어요"라는 말. 수업, 팀프로젝트, 알바, 동아리 — 모두 STAR로 분해하면 강점이 나옵니다. 경험의 크기가 아니라 그 경험에서 무엇을 했는지가 중요함을 강조하세요.

방향 설정 팁: 처음부터 하나를 못 고르는 수강생이 많습니다. "2개 방향으로 준비하면서 지원해보고 결정한다"가 현실적인 조언입니다.

면접관은 지원자가 우리 업계를 얼마나 아는지 봅니다. 모르면 탈락입니다. Claude로 업계 트렌드·회사 분석·직무 역량을 빠르게 파악해 '업계를 아는 지원자'로 보이세요.

"왜 우리 회사인가요?" 답변 힌트 # JD 키워드 추출 + 내 경험 연결 다음 채용공고(JD)를 분석해줘. [JD 내용 붙여넣기] [채용공고 전체 텍스트] 분석해줄 것: 1. 이 JD에서 반복되는 핵심 키워드 TOP 10 2. 필수 역량 vs 우대 역량 분류 3. 내 경험 [경험 요약]과 JD 연결 포인트 4. 이 JD 기반 예상 면접 질문 5개

MODULE 03 · DAY 10–14
M03 · 이력서

AI 이력서 최적화
— ATS 통과 + 채용담당자 주목

이력서는 5~7초 안에 판단됩니다. ATS(자동 스크리닝 시스템)도 통과하고, 사람도 읽고 싶게 만드는 이력서를 Claude와 함께 완성합니다.

📅 Day 10–14
📄 ATS 최적화
📊 성과 수치화
⏱ 약 95분
이 모듈을 마치면
  • JD 키워드를 자연스럽게 녹인 ATS 통과 이력서를 작성할 수 있다
  • "~담당했다" 대신 "~으로 X% 개선했다"처럼 성과를 수치화할 수 있다
  • 직무별로 이력서를 빠르게 커스터마이징하는 시스템을 만들 수 있다
이론 강의
1
이론
ATS란 무엇인가 — 기계가 먼저 읽는 이력서
16분

대기업의 80% 이상이 ATS(Applicant Tracking System)로 이력서를 자동 필터링합니다. JD에 있는 키워드가 이력서에 없으면 사람이 보기 전에 탈락합니다. 그래서 같은 경험이라도 회사·직무마다 다른 키워드로 표현해야 합니다.

❌ ATS 탈락 이력서

- 팀프로젝트 참여하여 맡은 역할 수행
- 고객 응대 담당
- 마케팅 업무 보조
→ 키워드 없음, 성과 없음

✓ ATS 통과 이력서

- 5인 팀 데이터 분석 프로젝트 리드, Python으로 처리 시간 40% 단축
- SNS 콘텐츠 기획·제작으로 팔로워 2,000명 증가 (3개월)
→ 키워드 + 수치 + 동사

이력서 최적화 + 성과 수치화 + ATS 점수
이력서 도구
# 경험 성과 수치화 다음 경험을 이력서 항목으로 최적화해줘. [원본 경험] [내가 했던 일을 자유롭게 설명] [지원 직무] [직무명] [JD 핵심 키워드] [JD에서 추출한 키워드들] 최적화 조건: - 강한 행동 동사로 시작 (이끌었다, 개발했다, 달성했다) - 수치 포함 (%, 명, 원, 배, 회 등) - JD 키워드 자연스럽게 포함 - 1~2줄로 압축 - 3가지 버전 제안 # 이력서 전체 ATS 점검 다음 이력서를 ATS 관점에서 점검해줘. [JD] [채용공고 붙여넣기] [현재 이력서] [이력서 내용 붙여넣기] 분석해줄 것: 1. JD 키워드 포함률 (%) 및 누락 키워드 목록 2. 각 항목별 개선 포인트 3. 개선된 버전 제안 4. 예상 ATS 통과 가능성 평가
🎯 DAY 10–14 미션
목표 JD 맞춤 이력서 1개 완성
가장 원하는 회사의 JD를 기준으로 이력서를 완성하세요. 모든 경험 항목에 성과 수치가 포함되어야 하고, Claude로 ATS 점검까지 마친 버전을 제출합니다.

자기소개서 전략
— 스토리텔링으로 차별화

"지원동기를 적어주세요"에 "귀사는 세계 최고의 기업이라서..."로 시작하면 탈락입니다. 기억에 남는 자소서는 나만의 구체적인 이야기에서 시작합니다.

📅 Day 15–19
📝 스토리텔링
🎯 지원동기 설계
⏱ 약 90분
이 모듈을 마치면
  • 자소서 각 항목에 맞는 스토리 구조(피라미드 원칙)를 적용할 수 있다
  • "지원동기 → 성장과정 → 성격 → 포부" 4대 항목을 차별화해 쓸 수 있다
  • Claude로 초안을 만들고 내 목소리로 편집하는 워크플로우를 완성할 수 있다
💡 합격 자소서의 공통점
"이 지원자라면 같이 일하고 싶다"는 느낌을 주는 자소서입니다. 스펙이 아니라 '이 사람은 어떤 사람인가', '우리 팀에서 어떻게 기여할 수 있나'를 보여주는 것이 핵심입니다.
