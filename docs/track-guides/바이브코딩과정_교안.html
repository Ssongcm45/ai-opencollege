바이브코딩이란
— 코딩 없는 개발의 시대

2025년 Andrej Karpathy(전 Tesla·OpenAI)가 처음 쓴 용어 "Vibe Coding" — AI에게 "이런 걸 만들어줘"라고 말하면 코드를 써주는 새로운 개발 패러다임입니다. 코드를 외우는 것이 아닌, 무엇을 만들지 명확하게 설명하는 것이 핵심 기술입니다.

📅 Day 1–4
💡 개념 이해
🧭 패러다임 전환
⏱ 약 80분
이 모듈을 마치면
  • 바이브코딩이 기존 개발과 어떻게 다른지 설명할 수 있다
  • Claude Code·Cursor·v0·Bolt 각 툴의 역할과 차이를 이해한다
  • 바이브코딩에서 가장 중요한 기술이 "설명 능력"임을 이해한다
이론 강의
1
이론
개발의 패러다임이 바뀌었다 — 코더에서 디렉터로
20분

과거의 개발은 문법을 암기하고 코드를 직접 타이핑하는 것이었습니다. 바이브코딩 시대의 개발은 "무엇을, 어떻게, 왜 만드는지"를 AI에게 명확하게 설명하는 것입니다.

❌ 전통 개발 방식

Python 문법 암기 → HTML/CSS 직접 작성 → 버그 수동 디버깅 → Stack Overflow 검색
→ 진입 장벽 높음

✓ 바이브코딩 방식

"사용자가 로그인하고 글을 쓸 수 있는 블로그 만들어줘. 디자인은 미니멀하게."
→ AI가 전체 코드 생성

바이브코딩의 핵심 역량
1. 명세 능력: 원하는 것을 구체적으로 설명하는 능력
2. 검증 능력: AI가 만든 결과물이 원하는 것인지 판단하는 능력
3. 이터레이션: "이건 아니고, 이렇게 바꿔줘"를 반복하는 능력
4. 디버깅 요청: "이 부분에서 오류가 나는데 고쳐줘"를 정확히 표현
툴주요 용도특징추천 대상

v0 (Vercel)UI 컴포넌트 생성프롬프트→React 컴포넌트, 실시간 프리뷰UI/프론트엔드 집중
Bolt.new풀스택 앱 즉시 생성브라우저에서 바로 실행, 원클릭 배포빠른 프로토타입

Q1 · 개념 확인
바이브코딩에서 가장 중요한 능력은?
①
Python 문법을 빠르게 타이핑하는 속도
②
Stack Overflow에서 답변을 빠르게 찾는 검색 능력
③
✓ 만들고 싶은 것을 구체적으로 설명하고, 결과를 검증하고, 수정 요청하는 능력
④
다양한 프로그래밍 언어를 알고 있는 것
💡 바이브코딩은 코드 문법보다 "무엇을 만들지 명확하게 표현하는 능력"이 핵심입니다. 좋은 프롬프트 = 좋은 결과물입니다.
