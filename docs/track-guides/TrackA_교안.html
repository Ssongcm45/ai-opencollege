이론 강의
1
이론
에이전트가 아니라 '생각하는 동료'다
12분

많은 분들이 Claude를 처음 열면 "이게 챗봇이야? 검색이야?"라고 생각합니다. 둘 다 아닙니다. Claude는 대형 언어 모델(LLM)을 기반으로 한 AI 어시스턴트로, 이전에 본 것이 없는 새로운 종류의 도구입니다.

검색 엔진은 이미 존재하는 웹 페이지를 찾아주는 도구입니다. Claude는 당신의 상황에 맞는 답을 새롭게 만들어냅니다. 이 차이가 전부입니다.

❌ 검색 엔진 방식

"이메일 작성법"을 검색 → 남의 이메일 양식 10개 확인 → 내 상황에 맞게 수정

✓ Claude 방식

"거래처에 납기 지연을 사과하는 이메일, 격식 있게 써줘" → 내 상황에 맞는 이메일 즉시 생성

핵심 문장
Claude는 "내 상황을 이해하고 함께 생각해주는 동료"입니다. 검색은 정보를 찾고, Claude는 답을 만듭니다.

Claude가 특히 잘하는 것: 글쓰기·편집·요약·번역·아이디어 생성·코드 작성·복잡한 분석. Claude가 못하는 것: 오늘 날짜 기준 실시간 정보, 인터넷 접속(커넥터 없이), 100% 정확한 수치 보장.

프롬프트 기초
— 잘 말하기의 기술

Claude와의 대화 품질은 프롬프트 품질과 정비례합니다. 같은 요청도 어떻게 말하느냐에 따라 결과가 10배 달라집니다. 잘 말하는 법을 체계적으로 배웁니다.

📅 Day 5–9
🎬 이론 강의 3편
✎ 실습 2회
❓ 퀴즈 4문항
⏱ 총 학습 약 80분
이 모듈을 마치면
  • 프롬프트의 4요소(역할·맥락·요청·형식)를 모든 요청에 적용할 수 있다
  • 첫 결과가 마음에 들지 않을 때 구체적인 수정 지시로 다듬을 수 있다
  • "잘 됐다"는 프롬프트를 저장하고 재활용하는 습관을 만든다
이론 강의
1
이론
프롬프트의 4요소 — RCRF 구조
15분

세계 최고의 프롬프트 엔지니어들이 공통적으로 쓰는 구조가 있습니다. R-C-R-F입니다.

요소영어질문예시
역할RoleClaude가 누구 역할을 할지"너는 10년 경력 카피라이터야"
맥락Context상황·배경·제약"B2B SaaS 제품, 40대 팀장 대상"
요청Request구체적으로 뭘 원하는지"제품 소개 슬라이드 제목 5개 써줘"
형식Format결과물 형태"각각 15자 이내, 번호 목록"
공식
좋은 프롬프트 = 역할 + 맥락 + 구체적 요청 + 원하는 형식
이 4가지를 다 담으면 결과물이 80% 이상 쓸 만해집니다.

가장 흔한 실수는 요청만 하고 맥락을 빠뜨리는 것입니다. "이메일 써줘"는 너무 범용적입니다. "거래처 담당자에게 납기 2주 지연을 사과하는 이메일, 격식 있게, 200자 이내"처럼 맥락을 담아야 바로 쓸 수 있는 결과가 나옵니다.

2
이론
첫 결과가 마음에 안 들 때 — 반복 개선법
10분

Claude의 첫 번째 답변이 완벽하지 않은 건 정상입니다. 중요한 건 어떻게 다듬느냐입니다. 이걸 이터레이션(반복 개선)이라고 합니다.

❌ 초보자 패턴

결과가 마음에 안 든다 → 포기하거나 처음부터 다시 쓴다

✓ 전문가 패턴

결과를 보고 → 뭐가 문제인지 파악 → 구체적 수정 지시 → 재생성

수정 지시 예시: "더 짧게" / "더 격식 있게" / "불릿 포인트 말고 표로" / "3번째 항목을 더 구체적으로" / "숫자 근거를 추가해줘"

핵심 습관
Claude를 단 한 번으로 완성하려 하지 마세요. 3–5번 대화로 다듬으면 훨씬 나은 결과가 나옵니다. 이게 Claude를 잘 쓰는 사람의 가장 큰 비밀입니다.
3
이론
슬롯 채우기 — 나만의 프롬프트 템플릿 만들기
12분

매번 프롬프트를 새로 짜는 건 비효율적입니다. 한 번 잘 작동한 프롬프트는 템플릿으로 저장해두고, 달라지는 부분만 채워 넣으면 됩니다. 이것이 슬롯 채우기입니다.

슬롯은 [대괄호]나 {중괄호}로 표시합니다. 이 부분만 매번 바꿔 넣으면 같은 품질의 결과가 반복해서 나옵니다.

핵심 프롬프트 예시
RCRF 구조 완성형 프롬프트
템플릿
# [역할] 설정 너는 [역할/전문가] 역할이야. # [맥락] 배경 설명 나는 [직무/상황]이고, [관련 배경/제약 조건]. # [요청] 구체적으로 [정확히 원하는 것]을 해줘. # [형식] 결과물 형태 [형식: 표/목록/문단/예시 수 등]으로 작성해줘. # 실제 예시: 너는 B2B 영업 전문가 역할이야. 나는 IT 솔루션을 판매하는 영업 대리이고, 내일 제조업 고객사 첫 미팅이 있어. 미팅 전에 파악해야 할 고객사 정보 체크리스트를 만들어줘. 10개 이내, 번호 목록, 각 항목마다 왜 중요한지 한 줄 설명 포함.

심화
