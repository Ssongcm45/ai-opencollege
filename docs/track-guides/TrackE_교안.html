Bloom's Taxonomy × Claude — 학습 목표의 과학
18분

좋은 수업은 명확한 학습 목표에서 시작합니다. Bloom's Taxonomy는 학습을 6단계로 구분하는 교육학의 핵심 프레임워크입니다. Claude에게 이 구조를 이해시키면 단계별 맞춤 학습 목표를 자동으로 만들어줍니다.

단계인지 수준동사 예시수업 활동 예시
1. 기억사실 회상나열하다, 정의하다, 말하다플래시카드, 요약 퀴즈
2. 이해의미 파악설명하다, 해석하다, 분류하다자기 말로 요약, 비유 만들기
3. 적용새 상황 적용사용하다, 실행하다, 풀다케이스 스터디, 실습 과제
4. 분석구조 분해비교하다, 분석하다, 구분하다A/B 비교, 구조 다이어그램
5. 평가판단·비평평가하다, 비판하다, 선택하다디베이트, 사례 비평
6. 창조새것 생성설계하다, 만들다, 제안하다프로젝트, 포트폴리오
Claude 활용 팁
"Bloom's Taxonomy의 각 단계에 맞게 학습 목표 6개를 만들어줘"라고 하면 Claude가 자동으로 단계별 목표를 만들어줍니다. 단계별 동사 목록을 함께 제공하면 더 정교한 결과가 나옵니다.
