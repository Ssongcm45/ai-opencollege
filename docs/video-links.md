# 영상 링크 입력

관리자 출강사례와 포트폴리오의 영상 링크에는 일반 YouTube 또는 Vimeo 공유 URL을 입력한다. 별도의 iframe 코드나 embed 주소는 필요하지 않다.

Vimeo의 일반 영상 주소, 채널·그룹·쇼케이스·앨범의 개별 영상 주소 및 기존 플레이어 주소를 지원한다. 공개 페이지는 이를 `https://player.vimeo.com/video/{id}`로 변환한다. 일부 공개 링크의 경로에 포함된 해시와 `h` 쿼리는 재생 주소에 보존한다. 추적 쿼리는 제거한다.

영상이 공개되어 있어도 Vimeo에서 외부 사이트 재생을 허용해야 한다. 도메인을 제한한 경우 실제 사이트 도메인도 허용해야 한다. URL 변환은 Vimeo의 접근 제한을 우회하지 않는다.

`npm run test:video`로 공유 URL 변환, 해시 보존, 잘못된 주소 거부 및 기존 YouTube 처리의 회귀를 검사한다.

2026-09-25 현재 등록된 영상의 Vimeo 공식 oEmbed 조회는 HTTP 200과 해당 영상의 플레이어를 반환했다. 같은 환경에서 플레이어 직접 요청은 연결 보안을 확인할 수 없다는 HTTP 401 안내를 반환했다. oEmbed 성공은 브라우저에서의 실제 재생 성공을 보장하지 않으므로 두 결과를 구분한다.
